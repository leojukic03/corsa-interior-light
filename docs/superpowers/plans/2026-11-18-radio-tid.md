# Corsa Radio na TID-u: plan provedbe

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dok svira Corsa Radio, TID pokazuje ime stanice (ili frekvenciju), a kod AF prebacivanja i promjene banda kratku poruku.

**Architecture:** Radio objavi MediaSession (naslov = PS ili frekvencija); Interior Light je već čita (`MediaListener` → `Hub.onMedia`) i šalje `N<tekst>`. Kratke poruke radio šalje broadcastom `hr.leo.corsalight.TID_MESSAGE`; Interior Light ih šalje Arduinu kao `L<tekst>`.

**Tech Stack:** Kotlin, Android `android.media.session.MediaSession` (bez androidx), JUnit 4 za čiste funkcije.

**Spec:** `docs/superpowers/specs/2026-11-18-radio-tid-design.md`

## Global Constraints

- Akcija broadcasta: `hr.leo.corsalight.TID_MESSAGE`, extra `"text"` (String), primatelj `setPackage("hr.leo.corsalight")`.
- Poruka na TID-u: `TextUtil.forTid(text, 10)`; prazna poruka se ne šalje.
- Formati: bez RDS-a `FM 98.50` / `AM 864`; AF `AF 100.20`; band `FM1` / `FM2` / `AM`.
- Interior Light → verzija 3.0.6 (versionCode 19), grana `main`. Radio → 0.2 (versionCode 2), grana `radio`.
- Bez novih biblioteka osim `testImplementation("junit:junit:4.13.2")` u radio modulu.

## Review Focus

- Dinamički PS (ime stanice koje se vrti po komadima): naslov sesije se mijenja često; Interior Light ga samo prosljeđuje. Očekivano: nema rušenja, TID prati. (Bez testa: ponašanje Interior Lighta je postojeće.)
- Radio ugašen (natrag) ili zatvoren: sesija STOPPED pa release → TID se vraća na idle. Task 2, korak "powerOff".
- Interior Light nije instaliran: broadcast nema primatelja, radio ne smije pasti. Task 2: `sendBroadcast` u try/catch.
- Poruka s dijakriticima ili predugačka (`AF 100.20` je 9 znakova): `forTid` je očisti i skrati na 10. Task 1 test.
- Demo način (emulator): sesija se objavljuje i u demu, broadcast se šalje i bez Interior Lighta. Ručna provjera u Tasku 3.

**Interfaces:**
- Consumes: `TID_MESSAGE` iz Taska 1 (ista akcija i extra, kopirani kao konstante; radio ne ovisi o modulu `app`).
- Produces: `object RadioTid { fun title(ps: String, freq: Int, am: Boolean): String; fun af(freq: Int): String; fun band(band: Int): String }`; `class RadioSession(ctx: Context) { fun update(title: String, subtitle: String, playing: Boolean); fun release() ; var onNext: () -> Unit; var onPrevious: () -> Unit }`; `Tuner.tidMessage(ctx, text)`.

- [ ] **Step 1: Test** `RadioTidTest`: `title("HRT-HR2", 9850, false) == "HRT-HR2"`, `title("", 9850, false) == "FM 98.50"`, `title("", 864, true) == "AM 864"`, `title("  ", 10790, false) == "FM 107.90"`, `af(10020) == "AF 100.20"`, `band(Tuner.FM2) == "FM2"`, `band(Tuner.AM) == "AM"`.
- [ ] **Step 2:** `sh ./gradlew :radio:testDebugUnitTest` → FAIL.
- [ ] **Step 3:** `RadioTid` (Locale.US za `%.2f`).
- [ ] **Step 4:** `RadioSession`: `MediaSession(ctx, "CorsaRadio")`, `isActive = true`, flagovi media buttons + transport controls, callback `onSkipToNext/Previous` → `onNext/onPrevious`; `update` postavlja `MediaMetadata` (TITLE = title, ARTIST = subtitle) i `PlaybackState` (PLAYING ili STOPPED, akcije SKIP_TO_NEXT|SKIP_TO_PREVIOUS|PLAY|STOP). U `Tuner`: session se stvara u `open(ctx)`, `onNext/onPrevious` = `nextPreset(±1)`; `changed()` poziva `session.update(RadioTid.title(ps, freq, isAm), radioText, source == 1)`; `powerOff()` → update(..., false); `close()` → `release()`.
- [ ] **Step 5:** `Tuner.tidMessage(text)` šalje broadcast (u try/catch) iz konteksta spremljenog u `open`. Pozivi: kod `RADIO 1` (band) ako se band promijenio → `RadioTid.band(band)`; u `afTick` kad AF uspije → `RadioTid.af(freq)`.
- [ ] **Step 6:** Testovi → PASS; `sh ./gradlew :radio:assembleDebug` prolazi.
